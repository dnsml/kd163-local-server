## 1. `87 → 88` 称号 / 成就列表

| 方向 | cmd | 载荷 |
|---|---|---|
| C→S | `87` | 空包（打开角色面板的称号页签） |
| S→C | `88` | `d0 88 00 07` + 14×`00` + 称号 varint（或 `00`） |

- 空表 = **19B**：`d0 88 00 07` + 14×`00` + `00`（末尾那个 `00` 是空 varint 占位）
- 有称号 = **21B**：`d0 88 00 07` + 14×`00` + `cd XXXX`（varint 顶掉末尾那个 `00`）
- 本地 `build_88()` 只读存档 `Player.title`；没有称号就回 19B 空表。
  以前按等级自动给 `cd0b7c`（2940，另一个号的称号），于是「一上线自带神界新丁、打个怪又消失」。

## 2. `885` / `886` 穿脱称号（本文件重点）

### 2.1 请求

```
C->S 885  seq=184  len=3  hex=cd03fc     ← 穿上：varint 称号 id = 1020「仙法小成」
C->S 886  seq=210  len=3  hex=cd03fc     ← 脱下：同样带该 id
```

payload 都只有一个 varint 称号 id。`cd03fc` 解出来是 **1020**。

### 2.2 应答（★ 反常：**两者都没有 ACK**）

真服完整时序：

```
C->S 885 (cd03fc)  17:17:04
S->C 29  len=53      ← 货币/资源
S->C 28  len=86      ← 属性（idx24 = 1020）
S->C 30  len=96      ← 装备外观

C->S 886 (cd03fc)  17:20:41
S->C 29  len=53
S->C 28  len=84      ← 属性（idx24 = 0，比上面短 2B）
S->C 30  len=96
```

`885/886` **连 ACK 都不回**，也不推 `178`——称号不是背包物品，穿脱不占格子、不消耗道具。
注意 `886` 的 `28` 只有 **84B**：称号从 `cd03fc`(3B) 变成 `00`(1B)，整包短 2 字节。

### 2.3 `28` 前后差异（token 级，41 token 只动 2~3 处）

| idx | 含义 | 穿之前 | 885 后 | 886 后 |
|---|---|---|---|---|
| 10 | 坐标 X（走动） | 33 | 30 | 30 |
| 11 | 坐标 Y（走动） | 6 | 7 | 5 |
| **24** | **称号 id** | **1019** | **1020** | **0** |

其余 token 全等：阅历 9943 不变、战力 2096 不变、货币一分不动。

### 2.4 称号 id 落在哪些包

| 包 | 位置 | 编码 |
|---|---|---|
| `17` | `off 52..54`（相对昵称后 `shift`） | `CD` + u16 |
| `28` | token **idx24** | varint（本地走 `tk[24]["value"]`） |
| `88` | 尾部 | `CD` + u16（无称号则单 `00`） |

`17` 的写法必须**定宽** `CD+u16`：17 的装备段是 6B 步进，货币/称号一旦变宽变窄，
后面整段前移，客户端按偏移读装备就错位。

## 3. 已知称号 id

| id | 名称 | 来源 |
|---|---|---|
| 1019 | 神界新丁 | 称号卡 `30059`（`182` 使用，等级 ≥5，否则不消耗） |
| 1020 | **仙法小成** | 2026-11-28 17:17 抓包，`885` 穿 / `886` 脱 |

- 脱下后称号为 **0**（`88` 回到 19B 空表、`28` idx24 写 `00`）。

## 4. 本地实现

| 位置 | 处理 |
|---|---|
| `local_server3.py` `build_88()` | 读 `cur().title`，无则 19B 空表 |
| `build_17()` `at(52)` | 定宽 `CD+u16` 写 `cur().title` |
| `build_28()` `tk[24]` | token 重编码写 `cur().title` |
| `182` + `TITLE_CARD` | 称号卡 `30059` → `cur().title = 1019`，推 `[88, 178]` |
| **`885` / `886` 分支（2026-11-28 新增）** | `885` 解 varint → `cur().title`；`886` → `cur().title = 0`；**都不回 ACK**，推 `29/28/30`，落盘 |

> 加这两个分支之前，命令在本地是「无模板静默丢弃」，所以点称号完全没反应。
