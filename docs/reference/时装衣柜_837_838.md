# 时装衣柜：837 / 838（使用时装卡为什么不穿上身）

> 2026-11-28 16:4x 定稿。真服样本：`relay.log` 13:50:37 / 23:57:14；
> 本地实测：`logs/server_stdout.log` 16:35:55、16:41:24。

## 协议

```text
C->S 837 (len=0)                打开衣柜 / 时装面板
S->C 838                        已拥有时装列表（同号回显 seq）

838 包体：
  [n 1B]
  n × { 0xCE + u32 时装 item_id  [1B 是否在穿]  [0xFF] }
  [1B 00]                       尾巴
```

真服 13:50:37 原始样本（9 件，全部未穿）：

```text
09 ce00015fa4 00 ff  ce00015fa6 00 ff  ce00015fb1 00 ff  ce00015fc5 00 ff
   ce00015fe3 00 ff  ce00015ff7 00 ff  ce0001600b 00 ff  ce0001601f 00 ff
   ce00016033 00 ff  00
```

- 条目里的 id 就是 `Item.xml` 里 `item_kind1=1 / item_kind2=14` 的**时装 item_id**
  （90033 快乐圣诞·男、90053 白色浪漫·男 …），不是形象卡对象号。
- 第 3 字节是**是否正在穿**：真服那个号只收藏没穿，9 件全 `00`。
- 这是**唯一**能把「当前穿哪件时装」告诉客户端的通道 —— 登录快照 `17` 里只有
  翅膀（off 172，24B），没有时装字段；`30` 的 11 格也只有 6 件防具 + 4 件首饰 +
  翅膀，没有时装槽。所以「用了时装卡却没换外观」只能靠 838 修。

## 使用时装卡（182）

真服：`182 [格位][数量]` → 空 ACK，时装卡**收进衣柜**（不再占背包格）。

本地以前只做「收进衣柜」：`cur().wardrobe.add(iid)`，838 里那件的穿戴位永远写 `00`
→ 玩家反馈「买了时装用了怎么没穿上」。现在：

1. `cur().wardrobe.add(iid)`（永久解锁，837 能查到）；
2. `cur().fashion[0] = iid`（当前穿着，存档 `fashion` 字段）；
3. `182` 空 ACK 后补推 `29 / 28 / 30 / 178 / 838`，838 里这件写 `01`。

存档：`Player.fashion = [None]`，`state_dict`/`load_state` 与 `wing` 同构。
