## 开发版怎么用

```bash
# 1) 本地三服务（必须后台托管）
python local_server3.py 9000 patch/local/exact.pem patch/local/exact.key
python local_http.py 80 192.168.0.111
python admin_server.py 8899

# 2) 模拟器通路（模拟器重启后必跑）
KD_DEV=emulator-5554 bash work/net_fix.sh
```

`net_fix.sh` 默认**只 DNAT `124.223.56.189`**，所以：

- 开发版（124.223.56.189）→ 进本地服 ✅
- 正式版（129.204.52.72）→ 走真公网，完全不受影响 ✅

## 为什么本地不能用正式版客户端

正式版内嵌 `CN=129.204.52.72` 证书、内置 IP 也是 `129.204.52.72`。
本地服就算 DNAT 把 `129.204.52.72` 兜到本机，服务端也必须出示同一张证书+私钥，
否则项目里 pinning 会直接拒（握手成功后零字节断开）。而那张证书的私钥在公网服务器上，
本地没必要拿它 —— 所以开发版单独一套证书（`patch/local/`）更干净。

需要拿正式版包临时打本地服时：

```bash
KD_RIPS="124.223.56.189 129.204.52.72" bash work/net_fix.sh
# 同时本地服要改成公网证书起：
# python local_server3.py 9000 patch/exact.pem patch/exact.key
```

## 换包/重装省流

资源在 `/data/data/<包名>/files`（约 128M），卸载会删。备份复用：

```bash
adb shell "su 0 tar -cf /sdcard/kd_backup.tar -C /data/data/com.kdxx.online files shared_prefs UserDefault.xml"
adb install -r 新包.apk
adb shell "su 0 mkdir -p /data/data/<新包名>"
adb shell "su 0 tar -xf /sdcard/kd_backup.tar -C /data/data/<新包名>"
adb shell "su 0 chown -R <新uid>:<新uid> /data/data/<新包名>/files /data/data/<新包名>/shared_prefs"
adb shell "su 0 restorecon -R /data/data/<新包名>"
```

`<新uid>` 用 `dumpsys package <新包名> | grep -m1 userId=` 取。

## 打包命令（复现）

```bash
# 开发版：在本地证书版 APK 上换包名 + 角标
python work/apk_coexist.py work/local/kd163_local_signed.apk work/coex/coex_unsigned.apk \
       --pkg com.kd163.dev --label "口袋修仙·开发版" --badge 开发
"/c/Program Files/Java/jdk1.8.0_162/bin/jarsigner.exe" \
  -keystore patch/kd163.keystore -storepass kd163key -keypass kd163key \
  -sigalg SHA1withRSA -digestalg SHA1 \
  -signedjar work/local/kd163_dev.apk work/coex/coex_unsigned.apk kd163
```

## 同一账号别双开

两个包同时登同一账号会写同一行存档，`rev` 冲突按最后写入者胜。
开发测试建议用独立测试号，或先在一个包上退到登录界面。
