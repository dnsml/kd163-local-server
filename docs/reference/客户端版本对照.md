## 开发版怎么用（直连，2026-11-27 23:1x 起）

开发包内置 `192.168.0.111`，**模拟器直连宿主即可，不用 DNAT、不用 adb reverse**。

```bash
# 1) 本地服务（必须后台托管：nohup & 会被回收，用 run_in_background / 计划任务）
python local_server3.py 9000 patch/local/host111.pem patch/local/host111.key
python local_http.py 80 192.168.0.111
python admin_server.py 8899

# 2) 起服务也可以走脚本（证书按 KD_CERT_BASE 选）
KD_CERT_BASE=host111 bash restart_srv.sh
```

注意事项：

- **证书必须成对**：包内嵌 `patch/local/host111.pem`，服务端就得用同一张+私钥；
  用回 `exact.pem`（CN=124.223.56.189）会握手成功但客户端 pinning 拒，零字节断开。
- **`work/net_fix.sh` 只给旧包用**（内置 124.223.56.189 的 `com.kdxx.online` 那版）。
  直连包不需要它；正式版（129.204.52.72）也不受影响。
- 换宿主 IP 时（比如从 192.168.0.111 变成别的）必须重新出包：见下面打包命令。

### 为什么内置地址要补斜杠

`192.168.0.111` 比 `124.223.56.189` 少 1 个字符，而 dex 的 `string_data_item`
在 data 段里是**顺序排布**的，ART 会按 map 顺序逐条校验：原地缩短后槽尾残留字节
会被当成下一条 string，真机直接 `Failure to verify dex file ... String longer than
indicated size 0` → `ClassNotFoundException` 闪退。

所以只能**等长替换**，缺的那个字符补在 host 之后、path 之前：

```
http://192.168.0.111/              (原 http://124.223.56.189)
http://192.168.0.111//assets.txt
https://192.168.0.111:9000//auth
```

服务端 `local_http.py` / `local_server3.py` 会把连续斜杠折叠成一条（`norm_path`）。

## 为什么本地不能用正式版客户端

正式版内嵌 `CN=129.204.52.72` 证书、内置 IP 也是 `129.204.52.72`。
本地服就算 DNAT 把 `129.204.52.72` 兜到本机，服务端也必须出示同一张证书+私钥，
否则项目里 pinning 会直接拒（握手成功后零字节断开）。而那张证书的私钥在公网服务器上，
本地没必要拿它 —— 所以开发版单独一套证书（`patch/local/`）更干净。

需要拿正式版包临时打本地服时：

```bash
KD_RIPS="124.223.56.189 129.204.52.72" bash work/net_fix.sh
# 同时本地服要改成公网证书起：
# python local_server3.py 9000 patch/exact.pem patch/exact.key
```

## 换包/重装省流

资源在 `/data/data/<包名>/files`（约 128M），卸载会删。备份复用：

```bash
adb shell "su 0 tar -cf /sdcard/kd_backup.tar -C /data/data/com.kdxx.online files shared_prefs UserDefault.xml"
adb install -r 新包.apk
adb shell "su 0 mkdir -p /data/data/<新包名>"
adb shell "su 0 tar -xf /sdcard/kd_backup.tar -C /data/data/<新包名>"
adb shell "su 0 chown -R <新uid>:<新uid> /data/data/<新包名>/files /data/data/<新包名>/shared_prefs"
adb shell "su 0 restorecon -R /data/data/<新包名>"
```

`<新uid>` 用 `dumpsys package <新包名> | grep -m1 userId=` 取。

## 打包命令（复现）

### 直连开发版（当前主力，2026-11-27）

```bash
cd /d/66666/kd163

# 0) 换宿主 IP 时要先重出一张同长度的证书（1151 字节，CN/SAN=新 IP）
python gen_cert_exact.py --cn 192.168.0.111 --want 1151 --out patch/local/host111

# 1) 改 dex（等长；缺的字符用 '/' 补在 host 后面）+ 换内嵌证书
python patch_apk.py --src "dist/口袋修仙-开发版.apk" --out work/local/kd163_dev_direct_raw.apk \
       --host 192.168.0.111 --cert patch/local/host111.pem --key patch/local/host111.key \
       --pad-slash --name HOST111

# 2) 去掉 patch_apk 自带的临时签名块（否则 META-INF 里有第二套 .SF/.RSA）
python - <<'EOF'
import zipfile
src="work/local/kd163_dev_direct_raw.apk"; dst="work/local/kd163_dev_direct_clean.apk"
dropped=lambda n: n.startswith("META-INF/") and n.split(".")[-1] in ("SF","RSA","DSA") or n.endswith("MANIFEST.MF")
zin=zipfile.ZipFile(src)
with zipfile.ZipFile(dst,"w") as z:
    for i in zin.infolist():
        if dropped(i.filename): continue
        z.writestr(i, zin.read(i.filename), compress_type=i.compress_type)
EOF

# 3) 用固定 keystore 重签（必须同一个，否则 -r 装不上；本机已装的是 kd163）
"/c/Program Files/Java/jdk1.8.0_162/bin/jarsigner.exe" \
  -keystore patch/kd163.keystore -storepass kd163key -keypass kd163key \
  -sigalg SHA1withRSA -digestalg SHA1 \
  -signedjar work/local/kd163_dev_direct.apk work/local/kd163_dev_direct_clean.apk kd163

# 4) 覆盖安装
adb -s 127.0.0.1:5555 install -r work/local/kd163_dev_direct.apk
```

## 同一账号别双开

两个包同时登同一账号会写同一行存档，`rev` 冲突按最后写入者胜。
开发测试建议用独立测试号，或先在一个包上退到登录界面。
