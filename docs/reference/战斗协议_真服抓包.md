## 开战包 151（35 字节）

```

```

拆：

| 字节 | 值 | 解读 |
|------|-----|------|
| `01` | 1 | 战斗类型（普通 PVE） |
| `0c` | 12 | 后续块长度 / 单位组数标志 |
| `06` + `a6` | 6 | 名字字节数（`a6`=`0xa0|6` 长度前缀） |
| `e8908ce696b0` | — | UTF-8「萌新」 |
| `0100` | — | 玩家阵营/位置 |
| `4c4c2f2f` | "LL//" | 玩家外形/职业参数编码 |
| `00` | — | |
| `a0000000` | — | 玩家血量/属性基值 |
| `0001` | 1 | 敌方单位数 = 1 |
| `ce0001b1fd` | 111101 | 敌方单位 ID（仙界守卫） |
| `50500000` | "PP" | 敌方外形参数 |
| `020107` | — | 回合/速度参数 |

## 回合操作 146（5 字节）

```
0107cdeac5
```

- `01` 动作类型（普通攻击）
- `07` 目标位/参数
- `cd ea c5` → `0xcd` 是 2 字节整数前缀，值 `0xeac5` = **60101** = 基础攻击技能 ID
  （客户端日志里 `list active skill learn 60101` 印证）

# 补：结算包 150 的掉落结构（2026-11-24 01:0x 真服抓包）

样本来源：`logs/relay.log` 里 58 份 `S->C cmd=150`（含 00:23~00:52 打世界BOSS那段）。

## 完整结构（58 份逐字节对齐，全部能刚好解析到 4 个尾 0）

```
[经验 变长][3B 未知，恒 00 00 00 或 00 00 xx][铜钱 变长][1B 未知，恒 00]
[u8 件数 N]{[物品ID 变长][u8 数量][u8 标记=1/2]}[4B 00 00 00 00]
```

关键实证：

| 样本 | hex | 解析 |
|---|---|---|
| 空手（len 11） | `0a` + 10×`00` | 经验 10 / 铜钱 0 / 0 件 |
| 2 件（len 21） | `00…00 02 cd4ec0 01 02 cd4ef9 01 02 00000000` | 0 经验 / 2 件 |
| 3 件（len 30） | `cd0dac 000000 cd1b58 00 03 …` | 经验 3500 / 铜钱 7000 / 3 件 |

- 铜钱恒等于 **经验 × 2**（3500/7000、4000/8000、2500/5000、5500/11000 四组全中）。
- **件数只出现过 0 / 2 / 3**，没有 1，也没有 4。
- 同一种物品的「标记」在 1 和 2 之间跳（20142 两种都出现过），与件数、等级都无关，
  按 1 下发即可，客户端显示无差别。

## 世界BOSS 现场观察（同批抓包）

用户 00:23~00:55 在真服和别的玩家一起刷世界BOSS，抓包里能确认的现象：

- 进战斗 `C->S 145` 的目标 id 就是 `113` 刷怪点里的世界BOSS：
  `ce000dbba1`=900001 九尾狐、`ce000dbba2`=900002 玄蜂（`Monster.xml` 里 `monster_type=4`）。
- `S->C 151` 里带着同场景其他玩家的名字（萌新 / 随便玩玩 / 玩偶姐姐 / 星辰望北），
  以及跟宠「功夫熊猫」——说明世界BOSS 是**同场景多人同屏打同一只怪**，
  客户端自己把附近玩家画进战场，服务端只下发名字/外观。
- 因此本地服只能复现「单人打世界BOSS」；多人同屏属于服务端广播 + 客户端绘制，
  不在单机回放的能力范围内。
- 真服世界BOSS 的经验是 3500~5500（玩家 lv45），比本地 `(6+lv*4)*2.5` 高一个量级；
  目前没抓到「怪物等级 ↔ 经验」的对应关系，先不动，避免又造出一张对不上的表。
