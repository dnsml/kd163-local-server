# 交接说明（给接手的 AI / 开发者）

一句话：这是《口袋修仙 / 梦幻神界》的自建服务端，协议靠真服抓包逐字节逆出来，纯 Python 标准库实现。
目标是把本地服做到能给真人发账号密码玩通全场（登录→建角→任务→战斗→背包→宠物妖灵→商城）。

---

## 1. 运行环境

| 项 | 值 |
|---|---|
| 服务端入口 | `local_server3.py <port> <pem> <key>`，默认 9000 |
| 端口分工 | 9000 游戏协议（仅 `/auth` 走 TLS，其余明文）；8080→80 资源 CDN |
| 服务端证书 | `patch/exact.pem`（md5 `126de957...`），必须与客户端 APK 内嵌的同一张 |
| 本地测试机 | 雷电 `192.168.0.111:5555`；正服/他服在 MuMu `127.0.0.1:7555` |
| 他服地址（观察用） | `124.223.56.189:9000`，经 `capture_proxy.py`（:19000）镜像 |
| 日志 | `logs/server.log`（本地）、`logs/relay.log`（真服/他服完整包序） |

抓包日志格式：`[时间] 方向 cmd=号 seq=号 len=长度 hex=原始字节`。`C->S` 是客户端上行，`S->C` 是服务端下行。
**分析任何行为都以 relay.log 的原始 hex 为准，不要相信任何二手描述。**

---

## 2. 帧格式

```
pack(cmd, seq, payload) = >HHI(6+len(payload)) + >H(cmd) + >I(seq) + payload
```
`len` 字段含 6 字节头。短字符串 = `0xA0|len + utf8`。变长整数 `enc_val`：
`<0x80` 单字节 / `0x80..0xFF` 用 `cc` / `0x100..0xFFFF` 用 `cd` / 更大用 `ce`+4字节大端。

## 4. 七个致命坑（踩过，别再回退）

1. **未注册 cmd 必须静默丢弃**。回 `cmd=1`（提示包）客户端 30ms 内 SIGABRT，无 Fatal / 无 tombstone。
   例外：登录期客户端主动请求但服务端不实现的 `22/542/663/1125/1134/1384`，**必须**同 seq 回 `cmd=1` 文本，
   否则 `loading m_depth` 归不了零，一直转圈。
2. **`enc_val` 分档错 = 收到 151 后干净退出**。这是「打怪闪退」的真凶，不是血量问题。
3. **`115` 要回两条 `118`**：`06<pos>` + `10<pos>`。不回的话客户端寻路走两步就停，永远发不出 `145`。
4. **`17/28/30` 的 `(性别,职业,等级)` 必须同源**。任一处用旧模板 → 等级乱跳 / 渲染线程段错误。
5. **`947` 不要自己解结构**，按「上阵妖灵集合」查真服原包回放（`res_cfg/pet_tpl.json`），猜结构会崩。
6. **`30` 尾部必须按真服长度写**：翅膀块**有没有翅膀都占 20B**，坐骑块**只有真有坐骑才写 6B**。
   无坐骑时多补 6B → 88B（真服 82B）→ 客户端整包丢弃，表现为「模型穿着整套装备、面板 11 格全空」。
   判定方法：剧情神装 6 防具 + 4 空首饰 + 武器 + 4B + 20B 翅膀 = **82B**，可以用 `work/test_newbie_char.py` 逐字节对比。
7. **`17` 是抓包号的快照模板，头部带旧货币和旧称号**。只动态化装备/等级/场景是不够的：
   `idx18~21` 货币、`idx22` VIP、`idx24` 称号都必须按存档**定宽**写回（不能走 token 重编码，
   否则包长缩短会让后面的定长装备段前移）。不改的话客户端先按 17 记账、再收到 28 真值，
   按差额弹「绑定铜币 -2,xxx,xxx / 元宝 -1749 / 绑定元宝 -4050」，并且登录时天生带一个不属于自己的称号。

## 5. 战斗数值模型（刚定稿，改动前务必读）

客户端**每回合固定扣 16 点**（打怪）/ **被扣 13 点**（挨打），这是客户端本地演算，服务端改不了。
所以 151 里下发的血量必须按回合数折算，否则「怪血还满着就弹胜利」：

```python
max_hp            = 16 * rounds_to_kill      # 怪
disp_player_hp_max = 13 * rounds_to_die     # 玩家
hp                = max_hp * 剩余回合 / 总回合   # 每回合等比掉，恰好结算那回合归零
```
`BATTLE_HP_TRUE=1` 可回退到配置真值（只用于对比观察，正常别开）。

伤害口径用 `panel_attr()`（与 `cmd=29` 同源，含装备/强化/套装/妖灵），**不要**再乘等级假系数。

回合动作：`action=1` 攻击（双方全额）；`action=4` 防御（**玩家不出手、宠物只表演不掉血、受伤减半**，
`PET_ATK_SHARE=0` / `DEF_TAKE_SHARE=0.5`）。纯防御永远打不死怪，`MAX_ROUNDS=20` 力竭判负。

  **「这只怪死了/从场景里消失」**，不是刷怪。铁证在 `logs/relay.log`：
  01:23:23 打死 900007 的致死后立刻 `S->C 121 ce000dbba7`，玩家 01:23:35 才 145 打下一只 900008；
  塔一层 23:43:59 的 `150` 之后紧跟 `121 ce002059a5`（=2120101）。
  所以**不能拿它刷怪**（发一次等于把怪判死），要重新摆怪就重推 `113 + 117`。

  塔层跳点带 `clear_needed="1"`，怪不清 → 下一层引导传送点不亮。**这两件事是同一个包**。
- `116` 无法区分「点 NPC」和「点怪」（都发 `payload=00`），所以无法用 116 精确开战。

## 7. 最快的上手方式

```bash
# 不用客户端也能验协议：直连 socket 跑探针
python work/probe_journey_defense.py     # 开始旅程 + 开战 + 防御回合 + 结算
python work/probe_pet.py                 # 宠物妖灵全链路
python work/test_battle_echo.py          # 148 回合回显回归
python work/test_pet.py                  # 962/964 六档长度回归
```

GM 走文件，不用开端口：往 `logs/gm.cmd` 写一行就执行。

```
打怪 2090101      # 直接推 151 开战（测战斗最快）
消怪 111101       # 推 121 = 这只怪从场景里消失（真服致死后的同一个包）
刷怪              # 重推 113+117，让客户端按对象表把怪重新摆出来
引路              # 直接过到本层「下一层」（等价于走到跳点发 128，塔里用来验引导点）
伤害 5            # 测试加速：打怪伤害 ×5（面板攻击力不变，只让一场 1~2 回合结束）；伤害 1 恢复
出塔              # 等价于客户端点「离开副本」发 132，回进塔前的场景（塔里/查不到则回洛水城）
神装 / 翅膀 / 妖灵 三只 / 元宝 +5000 / 战力 / 看角色
```

网页后台（默认 `127.0.0.1:8899`，**不随主服自动启动**）：

```bash
start_admin.bat                 # Windows 双击即可；等价于 python admin_server.py 8899
# 浏览器打开 http://127.0.0.1:8899
# 同网段设备要访问：set KD163_ADMIN_HOST=0.0.0.0 再启动
```

后台「测试加速」区有 `伤害 ×3 / ×5 / ×10 / 恢复 ×1` 和 `出塔` 按钮，走的是同一套 GM 指令。

每次改完代码：`bash work/relogin.sh`（自动重启客户端并登录，约 60 秒）。

### 干净 clone 的预期行为（2026-11-24 实测过，别当成 bug）

仓库**不带玩家存档**（`player_state*.json` 全在 .gitignore），所以第一次登录一定没有角色：

1. `cmd=17` → 服务端回 `cmd=1 01a0`（无角色）；
2. 客户端弹**建角界面**（男/女 + 昵称 + 创建）；
3. `cmd=20` → 157B 应答 + 113/117 → 开场剧情 → 蓬莱仙境 Lv1 未转职；
4. 点「开始旅程」→ `182` → 29/28/178，九天玄女对话 + 任务 400101；
5. 接（`211` 直接置可交）→ 交（`214`）→ Lv1 一口气升到 Lv4 → 推 29/28/88/210 接下一环。

想跳过建角直接造一个角色：

```bash
printf '建角 小林 男\n' > logs/gm.cmd            # 主号
printf '@1234567 建角 小林 女\n' > logs/gm.cmd   # 指定账号
```

**注意**：无参 `刷怪` 以前在 GM 线程里取 `cur_map`（主循环局部变量）会 `NameError`，
已改为从角色档取 `cur().scene`（2026-11-24 修）。
`刷怪` 也不再发 `121`（那是「怪死了」，越刷越空，2026-11-25 纠错）。
