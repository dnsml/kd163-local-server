## 0. 一句话结论

三天把「别人开的线上服」从**只能看不能碰**，做成了**本地可玩、可建角、可发账号**的完整服务端：
真账号登录 → 无角色 → 客户端建角 → Lv1 进图 → 任务链 → 战斗结算 → 背包/装备/强化 →
宠物/妖灵/称号/VIP/商城/合成，全链路按真服抓包逐字节对齐。**没有假登录、没有默认角色、没有客户端骗包。**

当前唯一明显的窟窿是**点怪自动寻路不稳定**（详见第 4 节第 1 条）。

### 别人拿到仓库后能不能直接跑？

**服务端侧能，客户端侧还差两个大文件。** 具体分工：

| 拿到什么 | 能做什么 |
|---|---|
| 只 clone 仓库（约 20MB） | 服务端起得来、`/auth` 通、协议探针全绿、能读全部配置表和抓包日志 |
| + 改包 APK `kd163_coexist.apk`（119MB） | 客户端能连上、能登录、能建角 |
| + 资源包 `res_update/mhsj_res.zip`（109MB） | 才能正常进主城/切图，缺它会在 native 层 abort 或卡加载 |

两个大文件都超 GitHub 单文件 100MB 上限，必须网盘/直传。清单与 md5 见 [`../README.md`](../README.md) 第二节。
换一台完全空的机器，按 README 第一、二节补齐后，流程和本机一模一样。
