# 战斗内名字只有两个字 / 迷宫任务提交不了

2026-11-24 16:4x 修复。

## 一、战斗内名字只有两个字

### 原因

上一轮定位「打怪闪退」时，我把 151 里的昵称**截断到 6 字节**，理由是「真服十档样本的昵称全是 6 字节『萌新』」。
那个推断是错的——真服抓包号本来就叫「萌新」，不是长度限制。

真正的闪退原因是 `enc_val()` 的整数分档（见 `../reference/战斗闪退_151整数编码.md`）。
分档修好后，昵称发完整名完全正常。

### 修复

`battle.build_open()` 里改成按**完整字符**累加到 ≤31 字节（`0xA0|len` 的上限）：

```python
nm = b""
for _ch in name:
    _cb = _ch.encode("utf-8")
    if len(nm) + len(_cb) > 31:
        break
    nm += _cb
```

## 二、迷宫任务 400802 提交不了

### 原因

任务 400802「回梦迷境」：

```xml
show_level="8"  task="35,1"  desc="去场景1021找NPC 20004进入迷宫"
```

**8 级就能接，但迷宫入口 1859 硬性要求 20 级**（真服的提示「此模式请达到20级后再来」）。
玩家 15 级时点「进入迷宫」被服务端拒绝 → `task=35` 永远不达成 → 任务停在「进行中」，交不掉，后面 400803/400901 全走不到。

### 修复

`local_server3.py` 的 `cmd == 1859` 分支，门槛从 20 改成 **8**（与任务 `show_level` 一致）：

```python
if cur().level < 8:
    return 1, err_text("此模式请达到20级后再来")
maze_ready[0] = True
return 1859, b""
```

`1859` 成功应答仍然是**同号空 ACK**（真服 ≥20 级的成功包没有样本），
客户端收到后正常关闭面板、回到场景，不会卡住。

主循环里原有的判定继续生效：

```python
if cmd == 1859 and maze_ready[0] and active_qid and \
        QUEST_TASK.get(qid_of(active_qid)) == 35:
    conn.sendall(pack(210, 0, quest_210_ready(_qi)))
    set_quest(_qi, True)
```

## 三、注意

- 迷宫只做了「点进副本即算完成」，**没有真的切迷宫场景**。真服 ≥20 级的成功包没有样本，
  等以后拿到再补场景切换。
- 门槛从 20 降到 8 是**本地服自己的取舍**，与真服不一致；如果要还原真服行为，把
  `if cur().level < 8` 改回 `< 20` 即可（但那样 8~19 级会卡在 400802）。
