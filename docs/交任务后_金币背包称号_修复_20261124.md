# 交任务后「金币变 / 背包空 / 称号消失 / 还是有宠物」定位与修复

时间：2026-11-24 14:30~14:45
现象来源：用户实测 17843661（百里海熠），14:28:44 交 400301 后反馈。

## 一、真服证据（先把「标准答案」钉死）

从 `logs/relay.log` 抓包取两个独立样本，交任务（214）后的推送序列是：

| 时间 | 号的状态 | 214 之后的包 |
|---|---|---|
| 15:37:08 | 未转职、无装备 | `214`(空) → `29`(28B) → `28`(62B) → `210`(8B，下一环进行中) |
| 23:55:41 | 主号、全套装备 | `214`(空) → `29`(45B) → `28`(82B) → `30`(96B) → `210`(12B) |

两条铁律：

1. **214 之后真服从不推 `178`**。178 是背包**全量**（客户端按包整体替换列表），
   本地服以前在 214 后补一发 `178`，等于用服务端记录去覆盖客户端背包 ——
   服务端背包记不全时，玩家看到的就是「交完任务背包里的东西没了」。
2. **`30` 只在身上真有装备时才推**（15:37 那个号没有 30）。空装备推 82B 模板，
   会把客户端外观刷成抓包号的快照。

## 二、改了什么（`local_server3.py`）

### 1. 交任务不再推 178（主因）

```python
send_push(conn, cid, 29)
_b28 = build_28(); conn.sendall(pack(28, 0, _b28))
if cur().equip or cur().wing[0]:      # 没装备就不推 30
    send_push(conn, cid, 30)
if _lv_before < 5 <= cur().level:     # 升级跨过 5 级，补推称号
    send_push(conn, cid, 88)
```

「重复交任务」分支（`qid_int in cur().done_quests`）同样去掉 178、30 改条件推。

### 2. 称号 `88` 改成动态 + 支持主动推

以前 `send_push(cid, 88)` 走 `TPL_PUSH` 的 21B 固定包：

- Lv<5 的号被推 88 → 凭空多一个「神界新丁」；
- Lv5 时升级了却没人推 88 → 客户端称号栏停在「无称号」。

现在 `send_push` 对 `87/88` 走 `build_88()`：

```
Lv<5   19B  d0 88 00 07 + 14×00 + 00        （无称号）
Lv>=5  21B  d0 88 00 07 + 14×00 + cd 0b 7c  （神界新丁，条件 task=30,5,1 即 5 级）
```

### 3. 战斗 151 不再无条件带宠物

`pet_proto.active_pet()` 原来不传参，任何号都会从 947 模板第一条读出「功夫熊猫」，
151 开战包就拼了宠物段 —— **这就是地图 947 已经跳过、宠物却还在的直接原因**。

```python
def active_pet(pets=None):
    if pets is not None and not list(pets):
        return None          # 没宠物 → 151 不拼宠物段
```

调用处改成 `pet_proto.active_pet(cur().pets)`。

## 三、金币「突然变了」是什么

`res_cfg/Quest.xml` 写得很清楚，新手链的奖励就是 **经验 + 绑定铜钱**：

| 任务 | 奖励 | 交完结果 |
|---|---|---|
| 400101 重归仙界 | exp 800 / 绑铜 200 | Lv1 → Lv4（连升 3 级） |
| 400201 命定之人 | exp 900 / 绑铜 500 | Lv4 → Lv6 |
| 400301 朱果补元 | exp 900 / 绑铜 500 | Lv5 → Lv7（绑铜 702 → 1202） |
| 400501 物归原主 | exp 1800 / 绑铜 2000 | 同时整套神装直接进装备栏 |

所以「金币变了」= 绑铜 +200/+500 的正常奖励，「等级跳」= 经验一次补满两级。
货币映射另有实证（`grant.py` 头部注释，来自真服逐次差额）：

```
idx18 = 绑定铜钱   idx19 = 绑定元宝   idx20 = 铜钱   idx21 = 元宝   idx22/23 = VIP
```

模板 token 实测：idx18=2304000、idx19=4030、idx20=0、idx21=869，与上面完全对上。

**新手任务一条物品奖励都没有**，所以新号交完任务背包仍是空的 —— 这是配置表决定的，
不是包被清掉。背包里要有东西，只能靠采集/打怪掉落真正入包（`bag_add`），
目前采集（124）只回 ACK 不入包，属于下一步要补的。
