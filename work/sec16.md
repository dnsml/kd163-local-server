## 十六、强化失败提示 / 强化石档位 / 强化石合成（2026-11-23 19:00）

### 16.1 「没钱也弹强化失败」的真正原因

客户端锻造面板有一套自己的结果码文案（`mirror/assets/configure/chinese.xml`）：

| 码 | 文案 key | 内容 |
| --- | --- | --- |
| 21 | `Forge_21` | 恭喜，强化成功！强化等级加1 |
| 22 | `Forge_22` | 很遗憾，强化失败了 |
| 23 | `Forge_23` | 装备不存在 |
| 24 | `Forge_24` | 你的元宝不足，不能自动购买材料 |
| 25 | `Forge_25` | 你的铜钱不够 |
| 26 | `Forge_26` | 你的材料不够 |
| 45 | `Forge_45` | 此装备强化等级已达上限，请升阶装备后再强化 |

**失败必须回 `cmd=822` + 1 字节结果码**，客户端才能弹出对应那句。
以前一律回 `cmd=1` 文本，客户端锻造回调等不到 822，只能兜底弹 `Forge_22`
「很遗憾，强化失败了」——所以没钱也只会看到这四个字，看不到原因。

本地日志实证（改之前，用户按住强化按钮连点）：

```
[18:47:52] [forge] 822 槽3 +9 需铜钱768000（现有 铜钱0 绑铜198664）-> 拒绝
[18:47:53] c003 <- cmd=822 seq=99  ... 同一秒内重试 9 次
```

客户端收不到 822 就自动重发，一秒内打了 9 次，然后弹一次「强化失败」。

现已改成：`822`(1B 码) → 23/25/26/45；只有客户端没有固定文案的
「强化石档位不够」才额外补一条 `04da` 长文本说明要换哪一档。

### 16.2 强化石档位表（Item.xml 20138~20154 原始描述）

| 强化石 | 灵石（防具/护符/时装/翅膀/法宝） | 仙玉（武器/戒指/坐骑） | 可强化区间 | 成功率 |
| --- | --- | --- | --- | --- |
| 初级 | 20141 | 20138 | **+1 ~ +3** | +5% |
| 中级 | 20142 | 20139 | +1 ~ +6 | +8% |
| 高级 | 20143 | 20140 | +1 ~ +9 | +12% |
| 特级 | 20457 | 20456 | +1 ~ +12 | +15% |

- 分类字段：`item_kind2=20` 强化仙玉、`21` 强化灵石、`22` 幸运石、`23` 保护符。
- 装备自身上限也是 +12（`Equip.xml` 只有 `strengthen_1..strengthen_12`，
  +8/+10/+12 还各带一个 `strengthen_N_gift` 附加属性）。
- 真服 18:30 那 18 次强化只用到了 +3 就停手，正是因为手里只有初级石——**完全对得上**。

**所以：初级强化石只能强化到 +3，+4 起必须换中级，+7 换高级，+10 换特级。**

### 16.3 本地已加的三道校验

1. 部位没装备 → 码 23。
2. 强化等级到 +12 → 码 45（"此装备强化等级已达上限"）。
3. 材料：没放石头 / 石头不在背包 / 类型不对（武器只能仙玉、防具只能灵石）/
   当前等级 ≥ 该石上限 → 码 26；档位不够时额外补长文本
   「初级强化灵石只能强化到+3，请换更高一级的强化石」。
4. 铜钱不足 → 码 25「你的铜钱不够」（不再含糊）。

顺带修掉的坑：以前 `材料段为空`（客户端发 `010a00`）也放行，
于是石头用完还能一路免费强化到 +9，花了 95 万绑铜全是白给。现在直接拒。

### 16.4 强化石合成：缺一份真服抓包

- 合成 UI 在「锻造 → 材料合成」/「宝石 → 宝石合成」（`Forge_27 合成宝石`、`gem_compound`）。
- 客户端配置里**没有合成配方表**：`Item.xml` 只描述"可在XX合成YY"，
  配方（几换几、要几张合成符、成功率）在服务端，本地没有。
- 强化石描述写的是「仙法迷宫获得」，不是合成获得；
  会明确写合成的只有 **品质石**（普通→逆天）和 **幸运石**（20144→20379）。
- 因此强化石合成这块还缺一样东西：**真服点一次「材料合成」的抓包**
  （输入材料 + 点合成，各一条 C->S，加回包）。拿到就能把 cmd 和配方一起还原。
