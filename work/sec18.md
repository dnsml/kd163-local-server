## 十八、强化石合成 / 技能按等级解锁 / 商城字段顺序（2026-11-23 19:2x 抓包）

这一节全部来自用户当晚在别人线上服的三次真实操作：
「做任务解锁了一个新技能」「解锁了师门竞技」「合成了一个初级强化石」。
抓包工具是 `relay.py`（19000 → 真服 9000），日志 `logs/relay.log`。

### 18.1 831 = 材料合成（强化石 4 合 1）

真服唯一样本（19:23:02）：

```
C->S 831 len=6 hex=01 cd4ead 01 04
     [0] 01          = 合成模式
     [1..] cd4ead   = 材料 20141 初级强化灵石
     [-2]  01        = 合成次数
     [-1]  04        = 每次消耗 4 个
S->C 178（全量背包，107B -> 114B）
S->C 831 len=0（空包）
```

背包差异（`178` 全量包逐格 diff，19:22:52 → 19:23:03）：

```
初级强化灵石  6 -> 2     扣 4 个
中级强化灵石  新增 x1
```

=> **4 个低档石头 = 1 个高一档石头**。两条链：

```
仙玉：20138 初 -> 20139 中 -> 20140 高 -> 20456 特
灵石：20141 初 -> 20142 中 -> 20143 高 -> 20457 特
```

本地实现 `synth_apply()` + 主循环 `cmd == 831`：
- 按材料查 `STONE_UP`，不在链里回「该材料不能合成」；
- 数量不够回「材料不足」（真服没抓到这个分支，先给明确提示）；
- **回包顺序必须是 178 在前、831 空包在后**（和真服一致），
  反了客户端会先关合成框再收背包，界面数字不刷新。
- 特级（20456/20457）是链尾，不能继续合成。

### 18.2 技能不是转职给的，是等级自动解锁

真服同一次登录内，306 从 1 条变 2 条：

```
19:20:5x  S->C 306 len=10  01 cd2775              = 10101
19:21:02  交完 401004（升到 12 级）
19:21:02  S->C 29 / 28 / 30 / 210 / 306 len=18
          02 cd2775 0000000000 cd27d9 0000000000  = 10101 + 10201
```

对照 `res_cfg/SkillLearn.xml`：

| 技能 | 名字 | class | min_level |
| --- | --- | --- | --- |
| 10101 | 仙心弈剑 | 1 | 10 |
| 10201 | 九天剑阵 | 1 | 12 |
| 10301 | 眩晕剑气 | 1 | 30 |
| 60101 | 回风流雪 | 6 | 1 |
| 60201 | 混元气刃 | 6 | 1 |

规则：**每个技能系列取最低档 id，min_level <= 当前等级就下发，按 id 升序**。
完美吻合三个真实样本：

```
未转职        -> 02 60101 60201  (18B)
御剑 Lv10     -> 01 10101        (10B)
御剑 Lv12     -> 02 10101 10201  (18B)
```

旧代码写死 `cls*10000+101`，升到 12 级也不会多出「九天剑阵」，
技能栏永远只有一招——这就是「假转职」残留的最后一处。

现在 `build_306()` 走 `skills_for(cls, level)`；交任务升级后如果技能表变了，
在 210 之后补推 306（对齐真服 19:21:02 的顺序）。登录回放同样走动态 306。

### 18.3 371 商城购买的字段顺序是 [ID][货币][数量]

旧代码按 `[ID][数量][货币]` 解析，错位：

```
19:22:51 C->S 371 len=5 cd4ead 02 05
         20141 / 02 / 05
         背包：初级强化灵石 1 -> 6（实际买 5 个）
```

若按旧解析就是「数量 2、货币 5」，既要扣错钱也少给 3 个。
现在改成 `cur = payload[i]`、`cnt = payload[i+1]`。

货币编码（结合三条样本）：

| 值 | 货币 | 依据 |
| --- | --- | --- |
| 01 | 元宝 | 20735 ×1 成功 |
| 02 | 绑定元宝 | 19:22:51 买 5 个成功（当时铜钱 0） |
| 07 | 铜钱 | 15:32:55 cd4f61 07 01 回「对应货币不足」（铜钱 0） |
