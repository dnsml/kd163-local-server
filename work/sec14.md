
## 十四、转职「假转职 / 卡任务 / 重复接两次 / 神装领两次」修复（2026-11-23 18:00）


### 14.2 假转职的三个真因（跑图是职业皮肤、进战斗打回原形）

离线构造器比对真服字节：

登录回放里的 306 也改成动态（c2 == 306 时用 build_306()），
否则转职后重登会被抓包快照刷回未转职技能 60101/60201。

### 14.3 「完成立即接两次 / 领两次神装然后卡死」

真服 211 应答的**尾字节本身就带可交标记**：

```
400401 (打怪) C->S 211 -> S->C ce00061bad 0001   # 进行中
400402 (对话) C->S 211 -> S->C ce00061c12 0101   # 直接可交
400501 (对话) C->S 211 -> S->C ce00061c75 0101   # 直接可交
```

这些样本后面**都没有再推 210**。我们以前在 211 之后再补一个
210(9B 可交)，客户端把它当成「又接了一次」→ 面板同一条任务两份 →
玩家点两次完成 → 神装发两次 → 客户端卡死。

修复：
- 删掉 211 后的 210 补推，可交状态只随 211 应答下发；
- 35 转职的推送顺序改成 36 -> 29 -> 28 -> 210(可交) -> 306；
- 35 的跟随推送从 [29,28,30,178] 收敛到真服的 [29,28]。

### 14.4 「交任务提交不了 / 一直重复」

214 命中 DONE_QUESTS（重登后客户端按本地进度重走任务链必然出现）时，
不再只回 28，而是走完整刷新 29 -> 28 -> 30 -> 178 -> 210(下一环进行中)，
只是不发奖励。任务状态（quest_active / quest_ready / quest_done）全部落盘。
